🎓 Digital ID Card Generator

A simple and modern web application to generate student ID cards instantly with QR Code integration and download as PNG feature.

🚀 Features

📝 Enter student details: Name, Roll Number, Course, Photo URL

👀 Live Preview of the ID card while typing

🔲 Student photo in square format

📱 Auto-generated QR Code containing student info

📥 Download ID card as PNG image

🎨 Stylish design with gradient background and card shadow

🛠️ Tech Stack

HTML5 → Structure of the app

CSS3 → Styling and layout (gradient, shadows, flexbox)

JavaScript (Vanilla JS) → Dynamic updates and QR generation

Libraries Used:

qrcodejs
 → Generate QR codes

html2canvas
 → Export ID card as PNG

📂 Project Structure
Digital-ID-Card-Generator/
│── index.html     # Main HTML file
│── style.css      # Styling
│── script.js      # Logic for live update, QR & download
│── README.md      # Documentation

📸 Workflow

User enters details (Name, Roll No, Course, Photo URL).

ID card updates instantly with entered details.

QR code is generated dynamically containing student information.

User clicks Download ID Card → PNG file is saved.

🔧 How to Run

Open index.html in any modern browser.

Enter student details → Preview updates live.

Click Download button to save the ID card.
